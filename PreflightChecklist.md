## Section 1: Pre-Bench Checklist
- [ ] Airframe fully assembled (verify wing, tail, landing gear secure)
- [ ] Control surfaces installed and centered
- [ ] Servos mounted and linkages adjusted
- [ ] Motor and propeller installed, secured, and balanced
- [ ] ESC mounted and calibrated
- [ ] Battery installed and secured
- [ ] Flight controller mounted and wired
- [ ] GPS/Compass installed away from interference sources
- [ ] FPV camera and VTX mounted (if applicable)

## Section 2: Bench Tests

### Power & Electronics
- [ ] Verify battery voltage and health
- [ ] ESC calibration completed
- [ ] UBEC or BEC output verified (5V or 6V as required)
- [ ] Servo function check (AIL/ELE/RUD/THR directions correct)
- [ ] Flight controller powers up and connects to configuration app

### Radio & Failsafe
- [ ] Transmitter and receiver bound (protocol confirmed: ELRS)
- [ ] Range check performed
- [ ] Failsafe configured (Throttle cut or Return-to-Home)

### Flight Controller Setup
- [ ] Firmware flashed (INAV or chosen firmware)
- [ ] Accelerometer calibration complete
- [ ] Compass calibration complete
- [ ] GPS lock verified (>8 satellites)
- [ ] Flight modes tested (ARM, ANGLE, ACRO, RTH)

### FPV System (Optional)
- [ ] Camera feed verified
- [ ] VTX channel and power set (legal limits)
- [ ] Antenna secured

## Section 3: Maiden Flight Checklist

### Pre-Flight
- [ ] Weather conditions acceptable (wind < 10 mph)
- [ ] Field clear and spotter present
- [ ] CG checked and within spec
- [ ] Control throws verified (low rates for maiden)
- [ ] Battery fully charged
- [ ] Propeller tight and balanced
- [ ] Range check repeated

### Flight Plan
- [ ] Takeoff direction into wind
- [ ] Perform gentle climb and level flight
- [ ] Trim adjustments noted
- [ ] Execute rectangular pattern
- [ ] Practice approach and landing

### Post-Flight
- [ ] Inspect airframe for damage
- [ ] Check motor, ESC, and battery temps
- [ ] Log flight data (INAV blackbox if enabled)
- [ ] Record trim settings and observations

---
**Tip:** Print this sheet and use a pen to check off each item before and after flight. Add notes for any anomalies or improvements needed.
